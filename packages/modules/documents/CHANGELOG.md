# @o2s/modules.documents

## 0.0.4

### Patch Changes

- 26d493b: chore(modules.documents): inherit `^build` instead of hardcoded build dependencies

    The package-level `turbo.json` pointed at `@o2s/utils.logger#build` and `@o2s/framework#build`. Those packages do not exist in projects generated by `create-o2s-app` (turbo fails with "Could not find package"), and overriding `dependsOn` with an empty list on `create-o2s-app/base` broke the monorepo build. The root `^build` covers both cases.
